# Line Parser

Line 群組聊天記錄解析工具，使用 React 19 + Redux 5 + React Router 7 建構。

## 技術棧

- **React** 19.x
- **Redux** 5.x
- **React Router** 7.x
- **Bootstrap** 5.x (react-bootstrap)
- **Webpack** 5.x
- **Sass**

## 安裝與執行

```bash
# 安裝依賴
npm install

# 開發模式
npm run dev

# 生產建置
npm run prod
```

## 專案結構

```
src/
├── actions/        # Redux Actions
├── components/     # React Components
├── reducers/       # Redux Reducers
├── routes/         # Route Components
├── stores/         # Redux Store
└── index.js        # Entry Point
```
